# PhotoBooth: загрузка будки напрямую с USB

Эта инструкция рассчитана на материнскую плату ASUS H81I-PLUS с BIOS 2305,
которая установлена в будке. После однократной настройки обычный запуск выглядит
так: питание будки -> загрузочная USB-флэшка -> Debian -> PhotoBooth на весь экран.

## Что понадобится

- новая USB-флэшка 16 ГБ или больше;
- Lenovo с Windows и Rufus;
- архив `PhotoBooth-BIOS-USB.zip`;
- клавиатура для первой настройки;
- старые рабочие флэшки, убранные в безопасное место.

Старые флэшки не форматируйте и не изменяйте. Во время создания новой системы
подключайте к Lenovo только новую флэшку.

## 1. Создание загрузочной флэшки

Следуйте `BOOTABLE_USB_WINDOWS_RU.md`. В Rufus используйте:

- схема раздела: `MBR`;
- целевая система: `BIOS или UEFI`;
- файловая система: `FAT32`;
- постоянное хранилище: не меньше 8 ГБ;
- режим записи: `ISO Image mode`.

После записи распакуйте комплект PhotoBooth на видимый раздел флэшки в папку
`PhotoBooth-Setup`.

## 2. Первый запуск через Boot Menu

1. Выключите будку.
2. Выньте обе старые флэшки.
3. Вставьте новую загрузочную флэшку и клавиатуру.
4. Включите будку и несколько раз нажмите `F8`.
5. Выберите `UEFI: <название новой флэшки>`. Если такого пункта нет, выберите
   пункт с тем же названием без `UEFI`.
6. В меню Debian выберите Live system с persistence.

На рабочем столе Debian откройте терминал и выполните:

```bash
cd /media/$USER/*/PhotoBooth-Setup
chmod +x *.sh PhotoBooth.Linux
./SETUP_KIOSK.sh
./VERIFY_KIOSK_BOOT.sh
```

Затем настройте принтер скриптом `CONFIGURE_DNP_RX1.sh` и перезагрузите будку.

## 3. Постоянная загрузка в BIOS

Войдите в BIOS клавишей `Delete` или `F2`, затем откройте вкладку `Загрузка`.

Установите следующие параметры:

- `Быстрая загрузка` -> `Отключено`;
- `Поддержка USB` -> `Все устройства` (не `Частичная инициализация`);
- `Ожидание F1 при ошибке` -> `Отключено`;
- `Вариант загрузки #1` -> `UEFI: <название новой флэшки>`;
- если UEFI-варианта нет, выберите обычный USB-вариант флэшки.

Для автоматического включения после подачи питания найдите:
`Дополнительно` -> `APM` -> `Restore AC Power Loss` и выберите `Power On`.

Не меняйте режим SATA: оставьте `AHCI`. Secure Boot сначала оставьте как есть;
отключайте его только если Debian отказывается загружаться.

Нажмите `F10`, подтвердите сохранение и дождитесь запуска PhotoBooth.

## 4. Нормальное поведение

- рабочий стол может быть виден несколько секунд во время загрузки;
- затем PhotoBooth открывается на весь экран, без курсора и рамки окна;
- при программном сбое приложение автоматически запускается снова;
- штатная кнопка выхода в защищённых настройках закрывает его без перезапуска;
- шаблоны можно положить на отдельную флэшку в папку `Templates`;
- при запуске они автоматически копируются в PhotoBooth.

## 5. Если PhotoBooth не открылся

Откройте терминал сочетанием `Ctrl+Alt+T` и выполните:

```bash
/opt/photobooth/VERIFY_KIOSK_BOOT.sh
tail -n 100 /opt/photobooth/logs/kiosk.log
```

Для ручного запуска:

```bash
/opt/photobooth/START_KIOSK.sh
```
