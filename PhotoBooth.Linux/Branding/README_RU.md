# Оформление PhotoBooth

Рабочая логика камеры, принтера DNP и сенсорного экрана не находится в этой
папке. Для изменения внешнего вида редактируйте только `theme.json` и, при
необходимости, добавляйте сюда изображения.

## Что можно менять

- `colors` — все основные цвета и точки градиентов;
- `font.family` — семейство шрифта;
- `sizes` — размеры текста, кнопок, скругления и основные отступы;
- `texts` — постоянные надписи интерфейса;
- `branding.logo` — имя PNG/JPG/WebP с логотипом из этой папки;
- `branding.background` — имя PNG/JPG/WebP с фоном из этой папки.

Пустые значения `logo` и `background` сохраняют нынешний вид. После изменения
оформления сохраните файлы отдельным коммитом и запустите на Mac
`СОЗДАТЬ ТЕСТОВОЕ ОБНОВЛЕНИЕ.command`. При повреждённом JSON приложение не
останавливается, а запускается со встроенным оформлением золотой версии.

Не переименовывайте ключи слева от двоеточия. Меняйте только значения справа.
