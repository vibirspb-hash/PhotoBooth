# Загрузочная флэшка PhotoBooth

## Что потребуется

- новая флэшка минимум 16 ГБ;
- Windows-ноутбук;
- Rufus;
- официальный Debian Live 13.6 Xfce amd64;
- папка `PhotoBooth-Linux-x64`.

Официальный ISO:

`https://cdimage.debian.org/debian-cd/current-live/amd64/iso-hybrid/debian-live-13.6.0-amd64-xfce.iso`

## Запись в Rufus

1. Подключить только новую флэшку. Старые рабочие флэшки убрать.
2. Открыть Rufus и выбрать новую флэшку в поле «Устройство».
3. Выбрать скачанный Debian ISO.
4. Схема раздела: `MBR`.
5. Целевая система: `BIOS или UEFI`.
6. Файловая система: `FAT32`.
7. Размер постоянного раздела: не менее `8 ГБ`.
8. Нажать «Старт» и выбрать режим записи ISO, если Rufus задаст вопрос.

ВНИМАНИЕ: Rufus полностью удалит содержимое выбранной флэшки.

После записи открыть видимый в Windows раздел новой флэшки и скопировать
туда всю папку `PhotoBooth-Linux-x64` под именем `PhotoBooth-Setup`.

## Первый запуск в фотобудке

1. Вставить только новую флэшку, камеру, принтер, клавиатуру и сетевой кабель.
2. В Boot Menu выбрать новую USB-флэшку в режиме UEFI.
3. Выбрать `Live system (persistence)`.
4. В Debian открыть папку `PhotoBooth-Setup` на флэшке.
5. Открыть терминал в этой папке и выполнить:

```bash
chmod +x *.sh PhotoBooth.Linux
./SETUP_KIOSK.sh
```

6. После установки выполнить:

```bash
./CONFIGURE_DNP_RX1.sh
./CHECK_LINUX_HARDWARE.sh
```

7. Перезагрузить компьютер и снова выбрать `Live system (persistence)`.
   PhotoBooth должен открыться автоматически.

Если пункта `Live system (persistence)` нет, флэшку пока не использовать для
мероприятия: обычный Live-режим потеряет настройки после перезагрузки.
